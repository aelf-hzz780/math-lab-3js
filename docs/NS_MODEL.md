## 有限几何模型

流管参数为 `u ∈ [0,1]`，壳层 `s ∈ [0.28,1]`，初始相位 `φ`。基准包络为：

```
R(u) = s[0.14 + 3.55 sin(πu)^0.82]
Θ(u) = φ + 2π w[0.68 + 0.52(1 − s)](u − 1/2) + 0.35 sin(2πu)
ρ = 1 − 0.6c
x = ρR(u) cosΘ / √λ
y = 5.6λ(1 + c/4)(2u − 1)
z = ρR(u) sinΘ / √λ
```

其中 `c ∈ [0,0.9]` 控制几何集中，`λ ∈ [0.65,1.6]` 控制拉伸，`w ∈ [0.3,2.6]` 控制缠绕。相位按黄金角分布并加固定 seed 的微小扰动；这改善空间均匀性，不代表物理统计分布。

`λ` 单独作用时变换矩阵为 `diag(1/√λ, λ, 1/√λ)`，其行列式为 1。独立的集中参数 `c` 不保持体积，因此这里没有宣称完整动画不可压缩。包络的 0.14 下界与有限参数范围确保任何显示帧都有有限、正的管心半径。

颜色参考的有界相对角速度指标为 `Ω(s,c) = 1/[0.24 + s²(1 − 0.6c)²]`。内层较快、偏琥珀色；外层较慢、偏青绿。示踪点沿有限曲线循环，端点循环是展示截断，不是物理边界条件。呼吸动画以 18 秒正弦周期改变 `c`，幅度截断在可用区间内，不趋向奇点。

此构造不是 Navier–Stokes 的已知速度场；没有计算压力、外力、黏性项、能量积分或误差估计，不应从画面推断它满足 PDE、形成奇点或重现论文证书。可切换到既有「有限核涡旋」实验查看独立的 Burgers 解析教学流场。

## 渲染与复现

高画质为 96 根流管，低画质为 56 根；横截面分别使用 7、5 个顶点，沿管分别使用 156、108 段，合并为一个带顶点色的几何体。流管、细线、示踪粒子分别批量绘制。逐帧只更新雕塑缩放与固定容量示踪缓冲；几何重建仅发生于缠绕参数或 seed 变化。切换实验释放几何、材质和灯光所在分组。

提供「经典纺锤」「集中与拉伸」「舒展涡旋」三个可复现预设，以及「沿轴心看」视角。暂停时首帧仍完整显示雕塑。纯数学测试先写入并确认缺少实现时失败，再验证：端点与极端参数有界、集中后的半径缩小、内层相对转速更高、单独拉伸保持仿射体积、循环可重复及无效参数拒绝。
